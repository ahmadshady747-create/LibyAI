# نظام الاستقبال والاستفسار الذكي لمصحة طبية عبر واتساب (LibyAI Clinic Bot) 🏥

نظام متكامل لتحويل رقم هاتف المصحة على واتساب إلى **موظف استقبال ذكي يعمل على مدار 24 ساعة**، مخصص للرد على الاستفسارات، وتوفير معلومات محدثة لحظياً حول جداول الأطباء وأسعار الكشوفات والتحاليل، مع آلية تحديث فريدة وفائقة السهولة عبر **قروب واتساب الإدارة** باللغة الطبيعية دون الحاجة للوحات تحكم معقدة.

---

## 🌟 المميزات الجوهرية للنظام

1. **الرد الفوري على مدار الساعة (24/7):**
   * الرد على جداول الأطباء المتواجدين اليوم وأوقات دوامهم.
   * إرشادات التحاليل الطبية (مثل: ساعات الصيام المطلوبة لتحليل السكر، وظائف الكلى، الدهون، شروط السونار).
   * أسعار الكشوفات والخدمات والتحاليل بالدينار.
   * التوجيه الصارم لآلية الحجز المعتمدة (الحضور الشخصي المباشر لمكتب الاستقبال) دون الدخول في إدارة الطوابير والحجوزات.

2. **التحديث اللحظي عبر قروب واتساب الإدارة (Natural Language Group Updates):**
   * يتجاهل البوت المحادثات والسوالف العادية داخل القروب.
   * يتدخل فور عمل إشارة له (`@Bot`) متبوعة بتحديث مثل:
     * `@Bot دكتور العظام علي اعتذر اليوم ومش حيكون متواجد.`
     * `@Bot كشفية عيادة العيون تغيرت من اليوم وصارت 50 دينار.`
     * `@Bot دكتورة الأطفال فاطمة حتبدأ الساعة 5 بدل الساعة 4.`
   * يقوم النظام بتعديل قاعدة البيانات فوراً، ويرد بتأكيد رسمي داخل المجموعة، وتنعكس المعلومة في نفس الثانية على أي مريض يراسل المصحة.

3. **ضوابط الأمان الطبي الصارمة (Strict Guardrails):**
   * **حظر التشخيص ووصف الأدوية:** يمنع البوت منعاً باتاً من تقديم تشخيص أو وصفات دوائية.
   * **بروتوكول الطوارئ:** التوجيه الفوري لقسم الإسعاف والطوارئ وأرقام سيارات الإسعاف عند استشعار حالات حرجة (ألم صدر، ضيق تنفس حاد، نزيف).

4. **محاكي تفاعلي حي (Interactive Web Simulator):**
   * واجهة ويب تحاكي شاشتي واتساب جنباً إلى جنب (شاشة قروب الإدارة + شاشة محادثة المريض + جدول قاعدة البيانات الحي) للاختبار الفوري والعرض التجريبي (Demo).

## 🚀 طريقة التشغيل السريع

### 1. تشغيل السيرفر والمحاكي التفاعلي:
من منفذ الأوامر (PowerShell / Terminal):
```powershell
python run.py
```

### 2. فتح المحاكي في المتصفح:
افتح الرابط التالي في المتصفح:
👉 **`http://localhost:8000`**

ستظهر لك شاشة متكاملة تضم:
1. **العمود الأيمن:** قروب واتساب الإدارة (جرب الضغط على أزرار التحديث السريعة أو اكتب بنفسك `@Bot دكتور العظام علي اعتذر اليوم...`).
2. **العمود الأوسط:** محادثة المريض على الخاص (جرب السؤال: *"من متواجد اليوم في العظام؟"* لترى انعكاس الاعتذار فوراً!).
3. **العمود الأيسر:** جدول قاعدة البيانات المباشر وحالة الأطباء والأسعار وسجل التعديلات (Audit Log).

### 3. تشغيل الاختبارات الآلية:
للتحقق من سلامة كافة المسارات والضوابط الطبية:
```powershell
python -u test_system.py
```

## 🔑 تفعيل الذكاء الاصطناعي السحابي (Google Gemini)

النظام مزود بنظامين متكاملين:
1. **نظام ذكي محلي (Rule-based & Regex):** يعمل بدون إنترنت وبدون أي مفاتيح API بكفاءة عالية.
2. **محرك Gemini 2.5 Flash:** لفهم أدق التفاصيل واللهجات الصوتية والنصية واستخراج البيانات بـ Structured Outputs.

لتفعيل Gemini:
1. قم بإنشاء ملف `.env` عبر نسخ `.env.example`:
```powershell
Copy-Item .env.example .env
```
2. ضع مفتاحك داخل ملف `.env`:
```ini
GEMINI_API_KEY=AIzaSy...
```

## 📱 الربط مع واتساب في بيئة الإنتاج (Production)

### الخيار 1: عبر Evolution API أو Baileys (الموصى به لدعم القروبات بدون تكاليف Meta)
1. تشغيل حاوية Docker لـ Evolution API.
2. مسح رمز الاستجابة السريعة (QR Code) لرقم هاتف المصحة.
3. ضبط الـ Webhook ليشير إلى:
   `https://your-domain.com/webhook/whatsapp`

### الخيار 2: عبر Meta WhatsApp Cloud API (الرسمي)
1. إنشاء تطبيق Business في Meta for Developers وتفعيل منتج WhatsApp.
2. ضبط الـ Callback URL في لوحة Meta:
   * URL: `https://your-domain.com/webhook/whatsapp`
   * Verify Token: `LIBYAI_CLINIC_VERIFY_TOKEN_2026`
3. إضافة المتغيرات في `.env`:
   ```ini
   WHATSAPP_TOKEN=EAAG...
   WHATSAPP_PHONE_NUMBER_ID=1029384756...
   ```
