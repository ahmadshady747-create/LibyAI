# LibyAI — مساعد خدمة العملاء الذكي للأنشطة التجارية الليبية (ماسنجر أولاً، واتساب ثانياً) 🏪

نظام متكامل يحوّل صفحة فيسبوك / رقم واتساب الخاص بأي نشاط تجاري ليبي (متجر، مطعم، مصحة، صيدلية، ورشة، مكتب خدمات...) إلى **موظف خدمة عملاء ذكي يعمل على مدار 24 ساعة**، مخصص للرد على الاستفسارات، وتوفير معلومات محدثة لحظياً حول الأسعار والتوفر وساعات العمل والجداول، مع آلية تحديث فريدة وفائقة السهولة عبر **رسائل الإدارة** باللغة الطبيعية دون الحاجة للوحات تحكم معقدة.

القناة الأساسية هي **ماسنجر** (Meta Messenger Platform)؛ واتساب قناة ثانوية اختيارية. التطبيق يعمل في وضع ماسنجر فقط بدون أي أسرار واتساب، ويدعم القناتين معاً عند تفعيلهما.

---

## 🌟 المميزات الجوهرية للنظام

1. **الرد الفوري على مدار الساعة (24/7):**
   * أسعار المنتجات والخدمات وأصناف القائمة وتوفرها بالدينار الليبي، من قاعدة بيانات حية (لا يخترع الأسعار أبداً).
   * ساعات العمل والعنوان وسياسات التوصيل والإرجاع والدفع، من ملف النشاط والأسئلة الشائعة.
   * جداول الأطباء وأوقات دوامهم وأسعار الكشوفات والتحاليل — للقطاعات الطبية فقط.
   * التوجيه الصارم لآلية الحجز المعتمدة دون الدخول في إدارة الطوابير والحجوزات.

2. **التحديث اللحظي باللغة الطبيعية (Natural Language Admin Updates):**
   * يتجاهل البوت المحادثات والسوالف العادية.
   * يتدخل فور عمل إشارة له (`@Bot`) متبوعة بتحديث مثل:
     * `@Bot سعر الشاشة صار 350 دينار.`
     * `@Bot الشاورما نفذت اليوم.`
     * `@Bot ساعات العمل صارت من 9 صباحاً حتى 10 مساءً.`
     * `@Bot دكتور العظام علي اعتذر اليوم ومش حيكون متواجد.`
   * يقوم النظام بتعديل قاعدة البيانات فوراً (ذرياً، مع إيصال تأكيد وسجل تدقيق)، وتنعكس المعلومة في نفس الثانية على أي عميل يراسل النشاط.

3. **ضوابط الأمان والتحويل للبشر (Guardrails & Handoff):**
   * **التحويل للبشر (كل القطاعات):** طلب إنسان/مدير، شكوى غاضبة، نزاع استرجاع، طلب جملة/خاص، أو استفسار خارج النطاق — يُحوَّل تلقائياً برسالة نظيفة مع رقم التصعيد ويُسجَّل في سجل التدقيق.
   * **الأمان الطبي (القطاعات الطبية فقط — مصحة، صيدلية، طبي):** حظر التشخيص ووصف الأدوية منعاً باتاً، وبروتوكول طوارئ فوري (تخطّي كامل للانتظار والذكاء الاصطناعي) عند استشعار حالات حرجة (ألم صدر، ضيق تنفس حاد، نزيف، فقدان وعي).

4. **محاكي تفاعلي حي (Interactive Web Simulator):**
   * واجهة ويب تحاكي محادثتي ماسنجر/واتساب جنباً إلى جنب (شاشة الموظف + شاشة محادثة العميل + الكتالوج وبيانات النشاط وسجل التعديلات الحي) للاختبار الفوري والعرض التجريبي (Demo)، مع مبدّل قناة (ماسنجر/واتساب).

│   ├── config.py               # إعدادات النظام والمفاتيح (قنوات + نشاط)

## 🚀 طريقة التشغيل السريع

### 1. تثبيت التبعيات ثم تشغيل السيرفر والمحاكي التفاعلي:
من منفذ الأوامر:
```bash
pip install -r requirements.txt
python run.py
```
`run.py` مخصص للتطوير المحلي فقط: يختار وضع التطوير ويربط على الجهاز المحلي.

### 2. فتح المحاكي في المتصفح:
افتح الرابط التالي في المتصفح:
👉 **`http://127.0.0.1:8000`**

ستظهر لك شاشة متكاملة تضم:
1. **العمود الأيمن:** محادثة الموظف الخاصة (جرب الضغط على أزرار التحديث السريعة أو اكتب بنفسك `@Bot سعر الشاشة صار 350 دينار...`).
2. **العمود الأوسط:** محادثة العميل على الخاص — ماسنجر افتراضياً مع مبدّل قناة (جرب السؤال: *"بكم الشاشة؟"* لترى انعكاس التحديث فوراً!).
3. **العمود الأيسر:** بيانات النشاط والكتالوج المباشر وحالة الأطباء والأسعار وسجل التعديلات (Audit Log).

### 3. تجربة قطاع آخر (بيانات تجريبية خيالية):
```bash
python seed_demo.py --sector retail       # متجر إلكترونيات
python seed_demo.py --sector restaurant   # مطعم
python seed_demo.py --sector workshop     # ورشة صيانة سيارات
python seed_demo.py --sector pharmacy     # صيدلية
python seed_demo.py --sector clinic       # مصحة (الافتراضي)
```
كل البيانات خيالية بالكامل — أسماء وأرقام وأسعار مخترعة للتجربة فقط.

### 4. تشغيل الاختبارات الآلية:
للتحقق من سلامة كافة المسارات والضوابط:
```bash
python -m pytest -q test_system.py test_system_integrity.py test_generic_multi_facility.py test_real_flow.py test_layer_authority.py test_security_regression.py test_sender_phone.py test_model_config.py test_channels.py test_multisector.py test_legacy_shims.py
```
الملفان `test_system.py` و`test_system_integrity.py` يعملان أيضًا كسكربتات مستقلة، لكن الأمر أعلاه هو الطريقة المعتمدة، وهي نفسها التي يشغّلها التشغيل الآلي عند كل دفع.

## 🔑 تفعيل الذكاء الاصطناعي السحابي (Google Gemini)

النظام مزود بنظامين متكاملين:
1. **نظام ذكي محلي (Rule-based & Regex):** يعمل بدون إنترنت وبدون أي مفاتيح API بكفاءة عالية.
2. **محرك Gemini (الافتراضي الحالي: gemini-3.1-flash-lite):** لفهم أدق التفاصيل واللهجات الصوتية والنصية واستخراج البيانات بـ Structured Outputs.

لتفعيل Gemini:
1. قم بإنشاء ملف `.env` عبر نسخ `.env.example`:
```bash
cp .env.example .env
```
2. ضع مفتاحك داخل ملف `.env`:
```ini
GEMINI_API_KEY=AIzaSy...
```

## 📱 الربط مع ماسنجر وواتساب في بيئة الإنتاج (Production)

قبل أي نشر، اقرأ `SECURITY.md` كاملًا. الخلاصة: البيئة الافتراضية هي الإنتاج وتفشل مغلقة بلا أسرار القنوات المفعّلة، والأسرار بلا قيم افتراضية، والمحاكي معطل في الإنتاج ما لم يُفعّل صراحة بمفتاح إدارة صحيح، وCORS بقائمة مصادر صريحة فقط. هذا المستودع عام وبيانات بذره خيالية بالكامل — لا تُدخل بيانات حقيقية أبداً في Git.

### القناة الأساسية: Meta Messenger Platform (الموصى بها)
1. إنشاء تطبيق في Meta for Developers وتفعيل منتج Messenger وربط صفحة فيسبوك الخاصة بالنشاط.
2. ضبط الـ Callback URL في لوحة Meta:
   * URL: `https://your-domain.com/webhook/messenger`
   * Verify Token: رمز قوي من اختيارك أنت، تضعه في `.env` (لا يوجد رمز افتراضي صالح)
   * اشترك في أحداث `messages` و`messaging_postbacks`.
3. إضافة المتغيرات في `.env`:
   ```ini
   ENABLED_CHANNELS=messenger
   MESSENGER_APP_SECRET=your_strong_meta_app_secret_here
   MESSENGER_VERIFY_TOKEN=your_strong_verify_token_here
   MESSENGER_PAGE_ACCESS_TOKEN=EAAG...
   MESSENGER_PAGE_ID=1234567890...
   ADMIN_SECRET_KEY=your_strong_admin_key_here
   ENVIRONMENT=production
   ```
   واعرض التطبيق خلف وكيل عكسي مع `LIBYAI_HOST` مهيأً صراحة؛ لا تعرّض `uvicorn` مباشرة للإنترنت.

### القناة الثانوية: Meta WhatsApp Cloud API (اختيارية)
1. تفعيل منتج WhatsApp في نفس تطبيق Meta.
2. ضبط الـ Callback URL:
   * URL: `https://your-domain.com/webhook/whatsapp`
   * Verify Token: رمز قوي من اختيارك أنت، تضعه في `.env`
3. إضافة المتغيرات في `.env` وتفعيل القناة:
   ```ini
   ENABLED_CHANNELS=messenger,whatsapp
   WHATSAPP_TOKEN=EAAG...
   WHATSAPP_PHONE_NUMBER_ID=1029384756...
   WHATSAPP_APP_SECRET=your_strong_meta_app_secret_here
   WHATSAPP_VERIFY_TOKEN=your_strong_verify_token_here
   ```
   بدون هذه المتغيرات يعمل التطبيق في وضع ماسنجر فقط، ويرد ويب هوك واتساب بـ 404.
